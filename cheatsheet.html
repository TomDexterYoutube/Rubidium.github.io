02 Variables & Mutability

All collections need mut to be modified. list.combine() joins values into a string. .len() and .has() work across collections. items(1).drop() removes that element and shifts the rest down (no Null left behind).

06 Control Flow

if x == 7 { ... } else if x > 10 { ... } else { ... } while count < 5 { ... } for i in range(1, 10) { ... } # end exclusive; loop var auto-dropped for item in my_list { ... } # list → values, index/dict → keys, file → lines break # exit loop continue # skip to next iteration

07 Functions

fn add(a: i32, b: i32) -> i32 { return a + b }

Parameters are always local — never enter the global pool. No overloading: duplicate names in the same scope = compile error. Return type is optional (defaults to nothing).

08 Memory

.drop()frees a variable immediately; collections free recursively; no Null left behind for collection elements
localkeeps a variable out of the global pool; dropped at scope exit
linkshares data between two variables instead of deep-copying; a plain = reassignment breaks the link
assignmentalways a full deep copy — Rubidium has no references or borrowing

09 Classes

class player() { let mut health: i32 = 100 fn take_damage(amount: i32) { health = health - amount } } let mut p = player() p.health = 80 # needs mut instance + mut field p.take_damage(10)

No self — fields are accessed directly inside methods. Instances deep-copy on assignment, same as everything else.

10 Error Handling

try { let bad: i32 = 10 / 0 } error { print("Error: " + error) # error is a str+ }

Only catches runtime errors (divide by zero, bad index, dropped memory, file/FFI failures). Type mismatches and mutability violations are compile errors — try never sees them.

11 Files

open("data.txt") as file { file.write("Hello") file.add(" World") let data = file.read() let line = file.readln(3) file.writeln(2, "Updated") for line in file { print(line) } } file.exists("x.txt") · file.new("x.txt") · file.delete("x.txt") file.rename("a","b") · file.copy("a","b") · file.list("dir/")

File handle closes automatically at the end of the block; variables created inside persist. Missing file on open() raises an error, creates the file, then continues.

12 Threading

use thread thread(my_fn(), 1) # run async with ID 1 thread.wait(1, 2) # block until threads 1 & 2 finish thread.running(1) # bool

Globals are shared across threads (no race protection). Parameters/locals/loop vars are private per-thread.
