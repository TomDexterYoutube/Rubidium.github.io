01
Read a file that might not exist

open() already creates a missing file and continues, but if you want to branch on that instead of just proceeding, wrap it in try / error.

safe_read.rubRubidium
try {
    open("settings.txt") as file {
        let contents = file.read()
        print(contents)
    }
} error {
    print("Couldn't read settings.txt: " + error)
}
02
Sum and average a list

A plain for loop over the list's values, accumulated into a mutable total.

average.rubRubidium
fn average(nums: list) -> f64 {
    let mut total: f64 = 0

    for n in nums {
        total = total + n
    }

    return total / nums.len()
}

let scores: list = [10, 20, 30, 40]
print(average(scores))   # 25
03
Shuffle a list and pick a winner

Seed once for reproducible results, shuffle in place, then grab the first entry — or just use random.choice() directly without shuffling at all.

raffle.rubRubidium
use random

let mut entries: list = ["Alice", "Bob", "Casey", "Drew"]

random.seed("raffle-2026")
random.shuffle(entries)

print(i"Winner: {entries(0)}")

# Or skip the shuffle entirely:
print(i"Winner: {random.choice(entries)}")
04
Divide safely

Divide-by-zero is a runtime error, not a compile error — so try / error catches it cleanly.

safe_divide.rubRubidium
fn safe_divide(a: f64, b: f64) -> f64 {
    try {
        return a / b
    } error {
        print("Division failed: " + error)
        return 0
    }
}

print(safe_divide(10, 0))   # prints the error message, returns 0
05
Count votes with an index

Since index().add() errors on an existing key, check with .has() first and branch between .add() for a first vote and .set() for every one after.

vote_count.rubRubidium
let mut votes: index = []

fn cast_vote(candidate: str) {
    if votes.has(candidate) {
        votes(candidate).set(votes(candidate) + 1)
    } else {
        votes().add(candidate, 1)
    }
}

cast_vote("Rubidium")
cast_vote("Rubidium")
cast_vote("Xeon")

print(votes("Rubidium"))   # 2
06
Nested settings with dict+

Group related settings under top-level keys, drilling down as deep as the data actually needs — no fixed schema required.

config.rubRubidium
let mut config: dict+ = {
    "display" = {
        "resolution" = [1920, 1080],
        "fullscreen" = [True]
    },
    "audio" = {
        "volume" = [80]
    }
}

print(config("display", "resolution", 0))   # 1920
config("audio", "volume").add(2)                # append a second volume value
07
Time how long something takes

Start a timer, do the work, read the elapsed time — same integer-ID pattern as threads.

timing.rubRubidium
use time

fn main() {
    time.timer_start(1)

    let mut total: i64 = 0
    for i in range(0, 1000000) {
        total = total + i
    }

    let elapsed = time.timer_read(1)
    print(i"Took {elapsed}s, total = {total}")
}
08
Run two independent tasks in parallel

Fire both threads, then block until both finish. Each keeps its own private locals — only globals need coordinating.

parallel.rubRubidium
use thread

fn download_task() { print("Download finished") }
fn process_task()  { print("Processing finished") }

fn main() {
    thread(download_task(), 1)
    thread(process_task(), 2)

    thread.wait(1, 2)
    print("Both tasks done")
}
Reminder: there's no automatic protection against two threads writing the same global at once — this recipe works because the two tasks don't share any state.
