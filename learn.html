Welcome to
The Rubidium Book

This book will teach you the Rubidium programming language from scratch — no prior systems programming experience required.

Rubidium is a high-performance, statically-typed compiled language designed to be approachable for beginners while scaling to real systems programming. It combines the clean, readable syntax of Python with the performance and safety guarantees of Rust.

Who this book is for

This book assumes you can write basic programs in any language — loops, variables, functions. You don't need to know C, Rust, or anything low-level. If you've written Python, JavaScript, or another high-level language, you're ready.

What you'll learn

  • How Rubidium's type system and memory model work
  • All three collection types — list, index, and dict
  • Functions, classes, and isolated scopes
  • Manual memory management with .drop()
  • Real hardware threading with POSIX threads
  • File I/O, error handling, and the standard modules
  • How to use Xeon, Rubidium's build manager, to compile and run programs

How this book is structured

Chapters build on each other. Read them in order if you're new to the language. If you already know the basics, feel free to jump to any chapter from the sidebar. Every chapter contains working code examples you can copy and run.

💡

File extension: Rubidium source files use the .rub extension. The build tool is called Xeon. You'll set it up in the next chapter.

Chapter 01

Getting Started

Install Xeon, create your first project, and run your first Rubidium program.

Installing Xeon

Xeon is the official build manager for Rubidium. You use it to initialise projects, compile code, and run programs. Install it by cloning the repository and running the install script for your operating system.

Linux / macOS
git clone https://github.com/TomDexterYoutube/Xeon-Rubidium
cd Xeon-Rubidium
./install.sh
Windows
git clone https://github.com/TomDexterYoutube/Xeon-Rubidium
cd Xeon-Rubidium
install.bat

Creating a project

Make a new folder and run xeon init inside it. Xeon will create the src/ directory and a main.rub entry point for you.

terminal
mkdir hello-world
cd hello-world
xeon init

Your first program

Open src/main.rub and write the following:

src/main.rub Rubidium 
fn main() {
    print("Hello, Rubidium!")
}

Now compile and run it:

terminal
xeon run

You should see: Hello, Rubidium!

The execution model

Rubidium programs run in two phases — understanding this now saves confusion later.

  • Phase 1 — Top level: Everything written outside a function runs first, top to bottom. Variables are created, functions are defined (but not called).
  • Phase 2 — Main: After the top level finishes, the compiler automatically calls fn main().
src/main.rub Rubidium 
print("Phase 1 — this runs first")

fn main() {
    print("Phase 2 — this runs second")
}
💡

Tip: Use xeon build to compile without running, and xeon run to compile and execute in one step.
